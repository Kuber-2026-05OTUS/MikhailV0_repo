Troubleshooting:
  If the site does not open, check Gateway and HTTPRoute status.

  1. Check resource YAML:
     kubectl get gateway {{ include "homework-app.gatewayName" . }} --namespace {{ include "homework-app.namespace" . }} -o yaml
     kubectl get httproute {{ include "homework-app.httpRouteName" . }} --namespace {{ include "homework-app.namespace" . }} -o yaml

  2. Check events and conditions:
     kubectl describe gateway {{ include "homework-app.gatewayName" . }} --namespace {{ include "homework-app.namespace" . }}
     kubectl describe httproute {{ include "homework-app.httpRouteName" . }} --namespace {{ include "homework-app.namespace" . }}

  Expected conditions:
    - Gateway:   Accepted=True
    - HTTPRoute: Accepted=True, ResolvedRefs=True

  If Gateway listener has PortUnavailable, check that the listener port matches the Traefik entryPoint port.

Inspect all namespace objects:
  kubectl api-resources --verbs=list --namespaced -o name | grep -v -E '^events|ciliumendpoint|podmetrics|endpointslice|endpoints$' | xargs -n1 kubectl get --show-kind --ignore-not-found -n {{ include "homework-app.namespace" . }}
